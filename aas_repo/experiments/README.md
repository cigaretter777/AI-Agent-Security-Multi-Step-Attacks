# Experiments

`extracted_modules/` contains historical attack/profile modules recovered from the final archive. They are preserved
with their original filenames and import assumptions for provenance. They are not the preferred public API of this
repository and may require the Kaggle competition SDK and original project import layout to execute directly.

Use `submission/attack.py` for the exact standalone final artifact and `src/aas_solution/` for small testable reference
utilities.
