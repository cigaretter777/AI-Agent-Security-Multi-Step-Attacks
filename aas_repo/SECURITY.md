# Security and responsible-use scope

This repository documents a solution to Kaggle's **AI Agent Security - Multi-Step Tool Attacks** competition.
The attack-generation code was designed for the competition's deterministic, offline sandbox and simulated tools.

- Do not point these techniques at real mailboxes, production agents, external accounts, or systems you do not own or have permission to test.
- Keep experiments inside an authorized sandbox or a locally controlled test harness.
- The repository is intended for reproducibility, post-competition analysis, and defensive agent-security research.

For repository bugs, open an issue without including credentials, private traces, or production secrets.
